# LOPQ + LEPEQBIO — Portal de Pesquisa UFMA

Primeira versão do portal institucional em Next.js.

## Executar localmente

1. Instale Node.js LTS.
2. Entre nesta pasta.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra `http://localhost:3000`.
